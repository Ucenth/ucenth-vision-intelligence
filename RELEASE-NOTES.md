# UCENTH Vision Intelligence 1.0

Open-source UCENTH Vision Intelligence by Universal Central Host - UCENTH.

This is the first official release of UCENTH Vision Intelligence: a browser-based visual intelligence project that identifies objects, understands people from context, reads and translates documents, and talks with you about what it sees, built as an educational open-source project. It runs on your own computer with a small Node.js server; identification, document analysis and the voice use Google's Gemini and Cloud Text-to-Speech services from your own Google Cloud project.

## What is included

- **Object intelligence.** Camera stability lock and 3 · 2 · 1 capture, or a JPEG/PNG upload. One clean frame goes through the local server to Gemini 3.8 Flash, which returns structured JSON: a cautious identification with visible details, conservative uncertainty and a next-view instruction when needed.
- **Hands-free conversation with the Charon voice.** After identification, Charon (Google Cloud Text-to-Speech) introduces the subject and Chrome speech recognition listens automatically. Answers are held until Charon audio is ready, then text and voice arrive together. Recognition and the microphone are off while Charon speaks; a five-second speech-start timeout pauses the conversation, and Continue conversation or a typed question resumes it. Typed questions work without a microphone.
- **Audio-reactive particle presence.** A WebGL2 particle field driven by real microphone and playback audio through the Web Audio API, with listening, thinking and speaking states, quality tiers for desktop, mobile and low-power devices, reduced-motion support and a Canvas fallback.
- **Contextual person intelligence.** When an image contains a person, identity is reported only if non-biometric context supplied with the image clearly establishes it, such as a caption under the photograph, a profile or leadership card, or an article heading. Otherwise the result is Person detected with a description of what is visible. There is no face recognition, face matching, biometric data or celebrity dataset. A name you state during the conversation is used as your own context, labelled as such.
- **Document intelligence and translation.** One Upload a File control accepts images, PDF (up to 15 MB and 60 pages, 25 of them scanned) and Word .docx (up to 10 MB). Documents are classified into broad types, their language is detected, key fields and a summary are extracted without inventing values, and non-English content gets an English translation beside the original with Original / English tabs, page navigation, right-to-left and CJK support. PDF text is extracted locally with PDF.js (script evaluation disabled); scanned pages are read by Gemini; Word files are parsed with mammoth without executing macros or embedded content. Uploads are validated by magic bytes and handled in memory only.
- **Educational edition.** Every HTML, CSS, browser JavaScript and Node file carries explanatory comments about intent and reasoning, and the [How To guide](how-to.html) combines installation with thirty lessons on how the project was built, real code excerpts with copy buttons, "Why?", "Try this" and "Common mistake" callouts, section search, and mini-lessons for reusing the camera, Gemini, voice, document and particle capabilities. Real-source excerpts are verified against marked regions in the code by `scripts/how-to-sync.js` during `npm test` and `npm run release:check`.

## Requirements

Node 22.19 or newer with npm (tested on Node 26.5.0 on Windows), Google Chrome, a camera, internet access, and a Google Cloud project with billing, the Agent Platform API (`aiplatform.googleapis.com`, formerly Vertex AI API) and the Cloud Text-to-Speech API (`texttospeech.googleapis.com`) enabled, and access to Gemini 3.8 Flash. Authentication uses Application Default Credentials on the server; no API key is placed in any file. Hands-free conversation needs a microphone and speakers or headphones. The [How To guide](how-to.html) walks through every step.

## Verification

Twenty-four unit and integration tests, eight Chrome suites (How To guide, scanner, appearance, responsive layout, audio, voice lifecycle, person states, document states), the How To source-sync check and the release secret scan pass. Two opt-in billable suites against live Gemini passed on synthetic fixtures generated at run time: eight contextual-person cases, and twenty-eight document cases covering English, French, Spanish, German, Portuguese, Italian, Arabic, Chinese, Japanese and Korean, text, scanned and mixed PDFs, Word files with tables, translation fidelity and grounded questions. A physical acceptance test with a real camera, laptop microphone and speakers completed six consecutive spoken follow-up turns with synchronized answer reveal, no self-triggered recognition and a correct silence pause. Measured particle performance was 60 fps on desktop and 30 fps in mobile mode.

## Privacy and limits

One captured frame, uploaded files and their extracted text, recognized questions and answer text go to Google's services under Google's data policies; live video never does, and raw microphone audio is never recorded by the application, although Chrome's speech recognition may process it remotely. Everything is held in memory for the session and cleared by Scan another object. Identification, extraction and translation are model judgment: uncertain values are marked or omitted, and important figures should be checked against the original. This is a local educational application, not a hardened public hosting service; the hosted UCENTH service applies its own operational limits, which are not part of this source.
